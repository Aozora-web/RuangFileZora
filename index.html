Tentang RuangFile

RuangFile adalah aplikasi arsip file berbasis HTML, CSS, dan JavaScript. File disimpan di penyimpanan browser pada perangkat ini menggunakan IndexedDB.

Catatan penting
File tidak otomatis diunggah ke server atau tersinkron ke perangkat lain. Jangan hapus data browser jika file masih dibutuhkan. Simpan salinan cadangan file penting.
