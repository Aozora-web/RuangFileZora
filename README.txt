RUANGFILE — Aplikasi Arsip File
================================

Isi folder:
- index.html : struktur halaman
- style.css  : desain dan tampilan responsif
- script.js  : upload, pencarian, filter, unduh, hapus, dan penyimpanan

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html menggunakan Chrome, Edge, atau Firefox versi terbaru.
3. Tekan Upload file atau seret file ke area upload.
4. File akan disimpan di IndexedDB browser pada perangkat tersebut.

Catatan:
- Ini adalah aplikasi frontend HTML/CSS/JavaScript tanpa backend.
- File tidak dikirim ke server dan tidak tersinkron ke perangkat lain.
- Penyimpanan bergantung pada browser/perangkat. Untuk file penting, simpan salinan cadangan.
- Untuk dipakai banyak pengguna atau mengakses file dari berbagai perangkat, diperlukan backend/server dan penyimpanan online.
